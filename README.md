# MPOS_Flask

A Point of Sale (POS) and E-Commerce web application built with Python Flask, Jinja2 templates, and SQLAlchemy.

## Features
- **Storefront & Client UI**: Browse products by category, view detailed specs, manage shopping cart, and checkout.
- **Admin Dashboard**: User management, authentication, role control, and file upload management.
- **RESTful API**: Endpoints for data queries and programmatic user management.

## Tech Stack
- **Backend**: Flask, Flask-SQLAlchemy, Flask-Migrate
- **Frontend**: Jinja2 HTML templates, Vanilla CSS & JavaScript
- **Database**: SQLite / MySQL
